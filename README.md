# タロットカード シャッフル演出デモ

クライアント提案用の動くプロトタイプです。
48枚のタロット風カードをシャッフルして1枚選ぶ「演出部分」だけを、ガチャ/カード召喚演出級の迫力でフロントエンドのみで再現しています。

DB・LINE連携・決済・管理画面・ログインは **含まれていません**(意図的に省いています)。

## 起動方法

```bash
npm install
npm run dev
```

ブラウザで <http://localhost:3000> を開いてください。

**スマホ縦型UI前提**のため、PCで確認する場合はブラウザの開発者ツールでモバイル表示(例: iPhone 14 Pro / 390×844)に切り替えると意図通りに見えます。

## 演出フロー(状態設計)

| フェーズ | 内容 |
| --- | --- |
| `opening` | 最初に「タップして始める」ゲートを表示(この操作で音声が解禁される)。タップするとBGM付きの本編(約10秒・タップでスキップ可)が始まる:闇と霧 → 光の粒子 → 宇宙的な背景 → 金色の魔法陣が浮かび上がる → カードの影が霧の中に現れる → 一斉に飛び出して渦を描く → 閃光 → 霧が晴れてトップ画面へ |
| `idle` | 中央にカードの山。山札がゆっくり上下に漂い、周囲の光が脈動。霧が流れ、粒子が舞う(完全静止しない) |
| `expanding` | ボタンで光のバーストと共に扇状に一気に展開。中央に魔法陣が出現(約0.7秒) |
| `storm` | 48枚が渦を巻いて舞う(約4.2秒)。傾いた楕円軌道+半径のうねりで**予測できない動き**になり、画面外への飛び出し・中央横断・カード同士の交差・奥から手前への接近(高速回転)が起きる。前面カードには残像、手前に迫るカードは縁がゴールドに発光 |
| `vortex` | 吸い込まれるように中央へ収束。光のリングが収束し、粒子がカードに吸い込まれる(約0.95秒) |
| `grid` | 閃光と共に6列×8行へ整列。「直感で1枚選んでください」 |
| `selected` | 整列後のタップで選択確定。選ばれた1枚がゴールドに発光しながら**ゆっくり中央へ浮き上がり**(約1.6秒)、浮上後に3Dフリップ。他のカードは暗転 |
| `result` | カード名「光の導き」とメッセージ、「もう一度試す」ボタン |

### シャッフル中のタップ反応(選択とは別扱い)

- **storm中**のタップ → そのカードが一瞬前面に飛び出し、少し拡大してゴールドの光で縁取られ、周囲に光の粒が飛び散る(約0.7秒で元のシャッフルへ戻る)。**選択確定にはならない**リアクション演出
- **整列後(grid)**のタップのみ選択確定として結果表示へ進む

## 技術構成

- Next.js 14 (App Router) / React 18 / TypeScript
- Tailwind CSS
- Framer Motion
- カード画像は使用せず、CSS + インラインSVGでタロット風の裏面・表面、魔法陣、粒子、光の軌跡をすべて描画
- 効果音はWeb Audio APIでリアルタイム合成(音源ファイル不要)

## サウンド

音源ファイルを一切使わず、Web Audio APIで効果音を合成しています。

| タイミング | 音 |
| --- | --- |
| オープニング | 低いドローン+風 → 鈴 → 魔法陣の上昇音と鐘の和音 → カードが飛ぶ風切り → 渦のライザー → 閃光のバーストと輝く和音(演出のタイムラインに同期) |
| シャッフル開始 | 風切り音(スウッシュ)+上昇するきらめき |
| シャッフル中 | 柔らかい風のループ(うねり付き) |
| シャッフル中のタップ反応 | 小さな鈴 |
| 渦への吸い込み | 下降する風 |
| 整列の閃光 | ノイズバースト+高いきらめき |
| カード選択 | ベルのアルペジオ+低音の余韻 |
| フリップ | 短いチャイム |
| 結果表示 | 柔らかい和音 |

- ブラウザの自動再生制限のため、ページアクセス直後の自動再生はできません。そこで最初に「タップして始める」ゲートを挟み、そのタップをきっかけにオープニングBGMを再生しています(ゲーム系サイトの定番手法)
- オープニングを途中でスキップするとBGMは即座にフェードアウトします(自然終了時は鐘の余韻がトップ画面まで残ります)
- 右上のスピーカーボタンでいつでもON/OFFできます
- iPhoneの本体サイレントスイッチがONの場合、iOS Safariの仕様で音は鳴りません(提案時の注意点)

## パフォーマンス設計(スマホ60fps狙い)

- アニメーションは **transform / opacity のみ**(レイアウトを発生させない)
- storm中の周回軌道はキーフレーム配列 + `repeat: Infinity` で、JSによる毎フレーム計算なし
- 前面で大きく舞うカードは約1/3(+手前に迫るクローズアップ数枚)、残りは小さく暗い背景レイヤーとして深度を表現
- motion blur風の残像は前面カードのみ(半透明グラデーションのゴーストが軌道を遅れて追従)
- 粒子・オーブ・光の軌跡・魔法陣の回転はすべてCSSアニメーション
- `box-shadow` はタップ反応中・選択カードなど同時に1〜2枚のみ
- `prefers-reduced-motion` 対応:CSSアニメーション停止+Framer Motion側も静的な配置に切り替え

## 本番実装に向けたメモ

- カードごとの結果は `src/lib/cards.ts` のデータを差し替えるだけで出し分け可能
- カード画像を用意する場合は `TarotCard.tsx` の裏面/表面を `<Image>` に置き換えるだけで演出はそのまま流用可能
- 効果音・BGM(カード展開音、選択時のきらめき音など)は今後の提案項目として未実装
