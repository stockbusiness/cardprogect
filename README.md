# タロットカード シャッフル演出デモ

クライアント提案用の動くプロトタイプです。
48枚のタロット風カードをシャッフルして1枚選ぶ「演出部分」だけをフロントエンドのみで再現しています。

DB・LINE連携・決済・管理画面・ログインは **含まれていません**(意図的に省いています)。

## 起動方法

```bash
npm install
npm run dev
```

ブラウザで <http://localhost:3000> を開いてください。

**スマホ縦型UI前提**のため、PCで確認する場合はブラウザの開発者ツールでモバイル表示(例: iPhone 14 Pro / 390×844)に切り替えると意図通りに見えます。

## 演出フロー

1. **初期状態** — 中央にカードの山。「カードを選ぶ準備をしましょう」
2. **シャッフル開始** — ボタンで扇状に展開(約0.7秒)
3. **シャッフル中** — 48枚が画面内をランダムに舞う(約1.5秒)
4. **整列** — 6列×8行のグリッドへ(約0.8秒)。「直感で1枚選んでください」
5. **カード選択** — 整列後のみタップ可能。選んだ1枚が中央に拡大し、裏面→表面へフリップ。他のカードはフェードアウト
6. **結果表示** — カード名「光の導き」とメッセージ、「もう一度試す」ボタン

シャッフル全体は約3秒で完了します。

## 技術構成

- Next.js 14 (App Router) / React 18 / TypeScript
- Tailwind CSS
- Framer Motion(アニメーションは transform / opacity のみを使用し、スマホでも軽量に動作)
- カード画像は使用せず、CSS + インラインSVGでタロット風の裏面・表面を描画

## 主要ファイル

| ファイル | 役割 |
| --- | --- |
| `src/components/CardShuffleDemo.tsx` | 演出全体のステートマシンとレイアウト(山札→扇→シャッフル→整列→選択) |
| `src/components/TarotCard.tsx` | カード1枚の見た目(裏面/表面)と3Dフリップ |
| `src/components/ResultView.tsx` | 選択後の結果表示(カード名・メッセージ・リトライ) |
| `src/lib/cards.ts` | 48枚分の内部データ(デモ用に全カード同一結果) |

## 本番実装に向けたメモ

- カードごとの結果は `src/lib/cards.ts` のデータを差し替えるだけで出し分け可能
- カード画像を用意する場合は `TarotCard.tsx` の裏面/表面を `<Image>` に置き換えるだけで演出はそのまま流用可能
